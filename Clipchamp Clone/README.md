# Clipchamp Clone

Multi-track video editor scaffold, built in the T9EditorLIT stack
(Svelte 5 + SvelteKit 2 + Tailwind 4 + Tauri 2 + Rust + FFmpeg).

This is a **scaffold with a working editing core**, not a finished editor.
Playback, persistence and rendering are deliberately stubbed so the parts that
are already correct stay testable.

- Reverse-engineering record: [`docs/REA-FINDINGS.md`](docs/REA-FINDINGS.md)
- Feature map source: [`evidence/feature-map.json`](evidence/feature-map.json)

## Quick start

```bash
npm install
npm run dev      # http://localhost:1424
npm run verify:fast
```

Tauri shell (needs Rust + the Tauri CLI):

```bash
npm run tauri dev
```

> The dev server uses port **1424** (the parent T9EditorLIT app uses 1420), so
> both can run side by side.

## Layout

```
src/
  lib/
    types.ts            domain model — derived from the REA feature scan
    timeline.ts         pure edit rules (split / trim / move / ripple / overlap)
    timeline.test.ts    25 tests, node --test, no framework
    editor.svelte.ts    Svelte 5 runes state + undo history
    ipc.ts              single typed choke point to Rust
    components/         Toolbar, MediaBin, Preview, Timeline, Inspector,
                        Captions, ExportPanel
  routes/+page.svelte   four-panel layout, mode isolation via {#key}

src-tauri/
  icons/icon.ico         generated by `node evidence/make-icon.mjs`
  src/
    lib.rs               #[tauri::command] declarations ONLY
    model.rs             serde structs, camelCase — mirrors types.ts
    timeline.rs          Rust mirror of timeline.ts, unit-tested
    probe.rs             ffprobe/ffmpeg argv construction, unit-tested
```

`lib.rs` holds no business logic, per `AGENTS.md`. Pure work lives in
`model.rs` / `timeline.rs` / `probe.rs` and unit-tests without a webview.

> `icons/icon.ico` is not committed as an opaque blob — it is generated by
> `evidence/make-icon.mjs`. It must exist for `cargo build` to run at all,
> because `tauri-build` needs it to emit the Windows resource section.

## Keyboard

| Key                       | Action                          |
| ------------------------- | ------------------------------- |
| `Space`                   | Play / pause                    |
| `←` / `→`                 | Step 1s (`Shift` for 5s)        |
| `S`                       | Split selected clip at playhead |
| `Ctrl+Z` / `Ctrl+Shift+Z` | Undo / redo                     |
| `Delete`                  | Delete clip, leave gap          |
| `Shift+Delete`            | Ripple delete                   |

## Zero-RAM constraints

This machine is an i3 with 8 GB and ~80% already used, so the scaffold
follows the rules in `AGENTS.md` throughout:

- **No media in the heap.** An `Asset` is a path plus metadata. Nothing decodes
  frames or audio in the browser.
- **One look filter chain, not many.** `lookToFfmpeg` emits only non-identity
  adjustments, so the common case passes no filter at all — every filter is CPU
  work on an i3.
- **Renderer is a short-lived FFmpeg child**, killed the moment it finishes.
  `probe.rs` only _builds_ argv, which keeps it testable without spawning.
- **Panel isolation.** `{#key editor.mode}` in `+page.svelte` destroys the
  previous component tree on mode switch.
